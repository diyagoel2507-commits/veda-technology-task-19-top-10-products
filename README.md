# VEDA Technology — Level 1 Day 19: Top 10 Products Analysis

## Project Overview

This project was completed as part of the VEDA Technology Level 1 Day 19 task.

The objective of this project is to analyze sales data and identify the Top 10 Products based on total sales using Microsoft Excel.

The analysis uses Pivot Tables to aggregate product-level sales and a bar chart to visualize the Top 10 products clearly.

## Objective

- Analyze product-level sales performance.
- Calculate total sales for each product.
- Identify the Top 10 products based on total sales.
- Sort products in descending order of sales.
- Check the Top 10 cutoff for possible ties.
- Present the results using a professional table and visualization.

## Tools Used

- Data Formatting

## Methodology

1. Maintained the original dataset in the Raw Data sheet.
2. Created a Pivot Table in the Sales Summary sheet.
3. Added Product Name as the row field.
4. Added Sales as the value field.
5. Summarized Sales using Sum of Sales.
6. Sorted products from largest to smallest based on total sales.
7. Applied a Top 10 filter to identify the highest-selling products.
8. Checked the cutoff for possible ties.
9. Created a separate Top 10 Products sheet.
10. Prepared a ranked table containing Rank, Product Name, and Total Sales.
11. Applied professional formatting to the final table.
12. Created a horizontal bar chart to visualize the Top 10 products.

## Deliverables

The completed Excel workbook contains the following sheets:

### 1. Raw Data
Contains the original transactional sales dataset.

### 2. Sales Summary
Contains the Pivot Table used to calculate total sales for each product.

### 3. Top 10 Products
Contains the final ranked Top 10 products table along with a visualization of total sales.

## Visualization

A Clustered Bar Chart was created to compare the total sales of the Top 10 products.

The horizontal bar chart provides a clear comparison of product-level sales performance and makes the ranking easy to understand.

## Key Outcome

The analysis provides a structured view of product-level sales performance and demonstrates how Excel Pivot Tables can be used to transform transactional data into a meaningful business summary.
